# Esercitazioni di fisica computazionale

Raccolta di sette brevi esercitazioni universitarie su programmazione scientifica, simulazioni numeriche e analisi di dati sperimentali. **Progetti didattici**, conservati con il codice originale per documentare il lavoro svolto durante il corso.

| Cartella | Argomento | Linguaggio |
| --- | --- | --- |
| `01-gravitational-field` | Campo gravitazionale e classi | C++ |
| `02-orbital-simulation` | Simulazione N-corpi e integrazione ODE | C++ / ROOT |
| `03-quantum-numerov` | Equazione di Schrödinger e Numerov | Python |
| `04-heat-and-wave-equations` | Equazione del calore e delle onde | MATLAB / Octave |
| `05-prism-monte-carlo` | Dispersione ottica e propagazione degli errori | Python / ROOT |
| `06-diode-characterization` | Acquisizione dati e fit I–V | Python / ROOT |
| `07-statistical-fitting-and-limits` | Fit binned/unbinned, test di Poisson e limiti statistici | Python / ROOT |

Ogni cartella contiene una descrizione breve, i file sorgente selezionati e, quando necessarie, indicazioni sulle dipendenze. Alcuni esercizi presentano ancora limitazioni o errori da correggere prima dell'esecuzione completa: vedere i rispettivi README e `CHECKLIST.md`.
