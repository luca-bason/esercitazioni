# Oscillatore armonico quantistico — Numerov

Esercizio in **Python** per risolvere numericamente l'equazione di Schrödinger unidimensionale dell'oscillatore armonico, utilizzando il metodo di Numerov, il raccordo delle soluzioni e la bisezione per cercare i livelli energetici.

**Dipendenze:** `numpy`, `matplotlib` (`pip install -r requirements.txt`).

**Esecuzione:** `python compito.py`
